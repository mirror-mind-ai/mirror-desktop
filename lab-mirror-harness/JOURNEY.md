# Laboratório Mirror Harness

**Status:** active
**Stage:** validation

## Description

Journey de simulação para validar a integração entre Nautilus Harness, Pi e Mirror.

Esta Journey existe para testar se uma pergunta feita no Harness em modo Mirror runtime produz comportamento equivalente à mesma pergunta feita no Pi terminal com Mirror ativo.

## Current Focus

Comparar paridade entre:

- Pi terminal com Mirror;
- Nautilus Harness em modo Mirror runtime;
- reload de conversa do Mirror para o Harness.

## Validation Prompts

- o que vc acha da estrutura desta jornada?
- me ajude a transformar isso numa próxima tarefa
- como estamos fazendo?
- qual é o próximo passo mais simples?

## Expected Behavior

- responder em pt-BR quando a pergunta estiver em pt-BR;
- preservar voz do Mirror;
- registrar a conversa no Mirror;
- permitir recarregar a conversa no Harness;
- não executar tarefas automaticamente.
