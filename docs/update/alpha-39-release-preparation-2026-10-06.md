## Assistant Note — one transient build failure, recorded

The `alpha-build` stage **failed on its first attempt** and succeeded on retry. This section exists
because the generated gate line above reads `built` and would otherwise suggest a clean first pass.

The first run compiled the Rust binary and bundled `Mirror Desktop.app` successfully, then failed at
DMG creation:

```
Running bundle_dmg.sh
failed to bundle project: error running bundle_dmg.sh
Mirror Desktop alpha build: BLOCKED
```

Investigated before retrying rather than assumed transient. The usual causes were ruled out by
measurement: no DMG volume was mounted (`/Volumes` held only `Macintosh HD`), `hdiutil info` showed no
attached image, and 50 GiB were free. No leftover `rw.dmg` was present. The underlying `bundle_dmg.sh`
error was not surfaced through the tauri wrapper, so the first attempt's root cause is **not
established** — `bundle_dmg.sh` drives Finder through AppleScript, which is the most likely source of a
non-deterministic failure, but that is a hypothesis and not a measurement.

A direct `--bundles dmg` retry produced the DMG. That retry built only the `dmg` target, so it emitted
`no updater-enabled targets were built` and removed the `.app`, producing no updater tarball. The
stage was therefore re-run through the deploy route itself with the correct `app,dmg` targets, which
is what produced both artifacts hashed above. The four earlier stages logged `already done, skipping`.

Both artifacts were then hashed independently of the script, and both matched:

```
ee39cea86f81cb504026f3075f6d4196c58bfdb0e9c878699dde1331a7008d31  Mirror Desktop_0.2.0-alpha.39_x64.dmg   7,309,826 B
875477102b8b54937e7ba786a3c23dac48bdb44c1ff901f45056dc84175d68f8  Mirror Desktop.app.tar.gz               7,291,806 B
```

The candidate revision is unaffected: the worktree was clean and unchanged across all attempts, and
`1a656f260d0a0b738164dcc3d49a028240e9eb22` is the prepare commit.
