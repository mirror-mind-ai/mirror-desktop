# v0.2.0-alpha.51 — A Model Per Conversation, and an App That Says Why It Stopped

**Date:** 2026-10-16

## Highlights

- **A model chosen in a conversation stays in that conversation.** Picking a model while you are in one no longer rewrites the default for the entire Journey.
- **The full selector writes what you were looking at.** Reaching it from inside a conversation and saving used to set the Journey default instead — the dialog was honest about its own scope, which was no help when you had opened it from a conversation.
- **That dialog now offers both**, conversation first: *Use model for this conversation*, with *Use model for this Journey* kept beside it.
- **"Use global defaults" now clears both**, so the button cannot promise more than it does.
- **The inherit option stopped naming a fallback it could not know.** With three levels, *inherit* means something different depending on which button you press next, so it now says *Inherit · do not set here* and names both defaults underneath.
- **When the provider refuses a turn, you see what it said.** Until now the attempt simply ended, and the provider's message existed on disk where nothing read it.
- **When finishing will not end, the app says why no exit is offered.** It had been making that decision correctly for months and drawing it as silence.

## Where We Started

Two unrelated field reports, five days apart, that turned out to share a shape.

The first was about models. A model picked inside a conversation did not stay there — and when that was repaired, the field found a *second* way to choose a model, sitting inches from the first, that wrote a different place entirely. Two controls in one menu, two different scopes, no way to tell them apart by looking.

The second was a turn that hung. A response had arrived, the composer sat on *Finishing*, nothing could be cancelled, and the only way out was to force-quit the application. It was the second time that day in the same conversation. Earlier the same morning, the same conversation had lost two turns to a provider that refused four times in a row and never said so on screen.

What they share is not a mechanism. It is that in each case **the application knew something and did not say it**. The model dialog knew its own scope. The finishing surface knew exactly why it would not offer an exit. The session file held the provider's words in full. Three silences, three different reasons, one experience.

## What Changed

### A model belongs to the conversation you chose it in

The agent profile now has three levels instead of two: a global default, a Journey override, and a conversation override. Choosing a model while you are in a conversation writes the conversation.

The repair came in three parts, and the third only appeared because the field looked again after the first two shipped:

| | |
|---|---|
| **The menu** | the quick model entries write the conversation you are in |
| **The full selector** | *"Open full selector…"* opened a dialog whose save was the **Journey** override — the other scope entirely |
| **The reset** | *Use global defaults* cleared only the Journey, leaving the conversation set while claiming otherwise |

The dialog was not re-pointed at the conversation, because it is the only place in the entire application where the Journey scope can be set at all. Instead it now offers both, with the conversation as the primary action.

Two smaller repairs were forced by that change. The dialog had been seeded from the Journey override, so it opened showing *inherit* while the conversation plainly held its own model; it is now seeded from what is actually in force. And *"Use global model · X"* became *"Inherit · do not set here"*, with *Journey default · …* and *Global default · …* named beside it — with three levels, inherit falls back to the Journey for a conversation and to the global for a Journey, so a label that named one of them was wrong half the time.

### When a turn ends badly, something is said

**The provider's refusal.** When a provider refuses, the message arrives as an entry in the session transcript rather than as the error event the application already knew how to read. After the last retry that entry is the final one on the branch, which is exactly the entry the interrupted-attempt notice already identifies. It now carries the provider's own words into the notice, bounded in length, and marked when it has been cut.

**The refusal to offer an exit.** When finishing runs long, the application decides whether it can offer you a way out. It refuses while it still records the agent as executing — correctly, because abandoning a turn that may be running is worse than waiting. That refusal was drawn as nothing at all. It is now a sentence, with the elapsed time and no button, appearing on exactly the same clock the offer would have used.

That timing matters more than it sounds. A healthy turn finishes with its lease briefly still held, so a sentence that appeared immediately would sit in front of every ordinary turn. It waits the full minute, which is long enough that the only turns reaching it are the ones genuinely stuck.

## Conscious Exclusions

- **No exit was added for a turn that is genuinely stuck.** This release explains the refusal; it does not override it. Offering to abandon a turn while the agent may still be executing needs a measurement the application does not take yet.
- **The cause of the hang itself is not fixed here.** The turn's durable record froze at *running* while the answer arrived seconds later, and nothing noticed because every recovery path reasonably treats *running* as a turn still in progress. That repair is scoped and deliberately held for the next release, so this one can be judged on its own.
- **No provider retry.** When a provider refuses, you are told; the application does not try again on your behalf.
- **The Journey scope was not removed**, only demoted. It is in use, and the dialog is its only entry point.

## What We Learned

**Two controls side by side must not write different places.** The model menu's quick entries and its full selector did exactly that for weeks, and both were individually defensible. The dialog's own honesty about its scope was no defence at all, because it had been reached from inside a conversation.

**A label that *can* be false has to be replaced, not qualified.** Once there were three levels, *inherit* genuinely meant two different things depending on what you pressed afterwards.

**A guard's name is part of whether it works.** One test here was called *"keeps the Settings Journey panel writing the Journey grain"* — and there is no Settings Journey panel. That wrong name kept a wrong belief alive across three rounds of work.

**Silence is a decision that nobody reviews.** The finishing surface refused to offer an exit for a defensible reason and said nothing, and the test that covered it asserted the screen was empty — folding "no exit was offered" and "nothing was said" into a single claim, so the silence was protected by the very guard meant to check it. The guard was narrowed to the half that was load-bearing rather than deleted.

**An answer is never lost, and the record should say so.** In the hung turn the response was complete and durable the entire time. What failed was the telling.

## Next Horizon

The hang itself. The application already holds two records that contradict each other when this happens — one says the turn is still running, another shows the answer already arrived — so recognising it needs no new source of truth, only a comparison of two that exist. That work waits on this release reaching the field first, because once a stuck turn is detected and recovered it stops being stuck, and the sentence this release added would never be seen.
