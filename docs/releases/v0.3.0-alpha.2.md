# v0.3.0-alpha.2 — The First Update

**Date:** 2026-10-31

## Highlights

- **Mirror Desktop TS updates itself.** Settings › Check for updates finds this version on the `/mirror-desktop/ts/` channel and installs it.
- **Nothing else changes.** Same Mirror core (`mirror-mind` 0.39.0), same Pi, same screens.
- **Your data stays put.** An update replaces only the application; your Mirror home, its memories, your settings, Pi and the key in your Keychain are not touched.
- **Mirror Desktop 0.2 is not offered this version.** Its channel still names 0.2.0-alpha.58.
- **Still Intel only, and not signed.**

## Where We Started

0.3.0-alpha.1 was the first release of the 0.3 line, published on a channel of its own. An installed
application that cannot update itself would need every later fix installed by hand, so the line is
not ready for daily use until one update has gone through end to end.

## What Changed

Only the version number. The application, its embedded Mirror core and its Pi are those of
0.3.0-alpha.1. The update is signed with the 0.3 line's updater key and published under
`/mirror-desktop/ts/`, where 0.3.0-alpha.1 looks for it.

## Conscious Exclusions

- **No fixes or features.** A version carrying both a change and the first update would not say which one failed.
- **The Mirror you already use is still not opened.** Bringing it into the application is the next step, planned with a backup and a way back to Mirror Desktop 0.2.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

The daily-use period planned for this line was set aside: on a new Mirror with nothing in it, there
was nothing real to use it for. Real use will start on the Mirror that holds real memory, which is why
that step comes with a backup and a tested way back.

## Next Horizon

The next step moves an existing Mirror to this line: a verified backup, the migration, the terminal
moved to the same core, and a rehearsed return to Mirror Desktop 0.2 if 0.3 stops working.
