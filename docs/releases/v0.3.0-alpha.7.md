# v0.3.0-alpha.7 — Your Skills, in This App's Home

**Date:** 2026-11-02

## Highlights

- **Mirror's skills write where this app reads.** When the agent uses one of your `mm-*` skills in
  a turn (a task, a journal entry, a memory), the `mirror` command now runs against the Mirror home
  this app opened. Before, it followed your terminal's configuration, which could name another home.
- **A conversation from the other build is named as such.** Opening a conversation that the
  development build made, or the other way round, says which build made it and that nothing was
  changed, instead of "needs recovery".
- **The development build is told apart at a glance.** Its sidebar reads "Mirror Desktop TS Dev",
  and Updates says it does not update itself, instead of "plugin updater not found". This build is
  unchanged there.
- **Still Intel only, and not signed.**

## Where We Started

Measuring alpha.5's turns showed that the agent can reach your `mm-*` skills, and that the `mirror`
command they run read the terminal's configuration rather than the home Mirror Desktop had opened:
a development build on a rehearsal home could have written to the person's own. The same day showed
a conversation opened by the wrong build reported as an invalid record, and an update check in the
development build ending in a plugin's error.

## What Changed

Each turn tells the `mirror` command which home to use: the bound home, its user, and its database.
The variables of the old Python Mirror are still removed. Refusing a conversation of the other
build now has a sentence of its own, read before any other reading of a failure. Updates follows the
same rule as the native updater: only the user build checks.

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.6. Your Pi skills still reach the agent, and
the turn still runs without the `mirror-mind` package's own extensions, so a turn is recorded once.
Mirror Desktop 0.2 is not offered.

## Conscious Exclusions

- **No separate icon for the development build.** The name and the badge were judged enough.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

Removing a variable is not the same as choosing a value. Taking the terminal's Mirror variables out
of the turn left the `mirror` command free to find another home on its own; naming the home closes
that door.
