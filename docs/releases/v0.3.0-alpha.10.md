# v0.3.0-alpha.10 — A Turn Ends Quietly

**Date:** 2026-11-03

## Highlights

- **No flash when the agent finishes.** The conversation stays in place at the end of a turn
  instead of being drawn again from the top.
- **No freeze after the answer.** In a conversation of production's size (6,196 messages, 34 MB
  stored), the longest pause on the page at the end of a turn fell from 12 s to 0.21 s.
- **Still Intel only, and not signed.**

## Where We Started

In long conversations, the Conversations area flashed hard when the agent finished, and the app
seemed stuck for several seconds afterwards (CR184). The output also felt slow during a turn
(CR185).

## What Changed

- A finished turn is settled on the conversation already on screen, plus the Mirror's confirmation,
  instead of on a copy read back from disk that lacked what the screen derives from Pi.
- Each save sends only the loaded chapter. Keeping the earlier history, messages and the record of
  agent actions, is now done by the native save, which already read the stored file. Before, the
  page read and parsed the whole conversation before every save.
- The checks before and after the Mirror records a turn read only identity and the turn ledger,
  not the messages.
- A save at production's size went from 32.6 MB to about 1 MB.
- The Working glow now fades on its own layer and respects the reduced-motion preference in the
  conversation list too.

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.9. The stored conversation keeps every
message and every record of agent actions; loading earlier chapters reads them back. Mirror
Desktop 0.2 is not offered.

## Conscious Exclusions

- **The native save still takes a few seconds** on a very large conversation, off the page's main
  thread.
- **The page still does measurable work per frame while text streams.** It is not felt, so it is
  not changed.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

The slow frames first measured during a turn were the recording's Screenshots instrument, not the
app. And one of two changes made together tripled the cost it meant to cut; they had to be
measured apart.
