# v0.3.0-alpha.3 — Ready for the Mirror You Already Have

**Date:** 2026-11-01

## Highlights

- **Adopt an existing Mirror home.** Choose a home made by an earlier Mirror and the app shows what it holds and what will change. Nothing is touched until you confirm, and the Mirror core takes a verified backup before it updates the home.
- **A turn after an interrupted one now finishes.** If a turn was cut off after Pi had recorded your request (a quit, a crash), the next turn used to answer and then sit at *Finishing* for good. It now finishes on its own, and the stranded turn is recovered when the app reopens.
- **Same Mirror core** (`mirror-mind` 0.39.0) and the same Pi.
- **Mirror Desktop 0.2 is not offered this version.** Its channel still names 0.2.0-alpha.58.
- **Still Intel only, and not signed.**

## Where We Started

0.3.0-alpha.2 proved the 0.3 line updates itself, on a new Mirror with nothing in it. The next step is
real use on a Mirror that holds years of memory, and the application could not yet open one.

## What Changed

**Adopting a home.** Settings › Choose Mirror home… accepts a home created by an earlier Mirror. The
review shows the home's path, how many Journeys, Conversations, memories and personas it holds, and
each change the update applies. The update runs only behind the core's backup, kept and checked in
the home's `backups` folder. Afterwards Mirror Desktop 0.2 and the terminal's Python Mirror can no
longer open that home; the review says so before you confirm.

**Finishing a turn.** Before each run the app records where the conversation ends, so it can tell the
new turn from what came before. It used to take the end of the last *complete* turn. When a request
was left unanswered after that point, the new run was mistaken for that older request, it appeared to
have started before it was asked, and the record of the turn refused to close. The app now takes the
conversation's actual end. On an ordinary conversation the two are the same, so ordinary turns are
unchanged. Found while rehearsing the move of a real Mirror to this line, and checked there.

## Conscious Exclusions

- **Moving the 0.2 conversations into 0.3 is not part of the app.** It is a rehearsed script run once, on the day a Mirror moves.
- **Recover this turn can still do nothing** on a turn whose record is still running. Captured as CR166, to be fixed after the move.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

Two rehearsals on a copy of a real Mirror found what months on a fresh home could not: sessions that
remembered the wrong working folder, model choices that stayed behind, and a turn that could never
finish. Each was fixed and rehearsed again before this release.

## Next Horizon

The production Mirror moves to this line: Mirror Desktop 0.2 is set aside, its home is kept as it was
and a copy is adopted, the 0.2 conversations are carried, and the terminal moves to the same core.
