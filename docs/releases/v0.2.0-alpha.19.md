# v0.2.0-alpha.19 — A Quiet, Truthful Surface

**Date:** 2026-09-25

## Highlights

- Stops flashing `Conversation synchronization needs attention` while automatic repair is still working.
- Stops flashing `Resolve the preserved attempt` after cancelling a turn.
- Delivers the typed request to Mirror instead of the authority envelope, the attachment block or the `/skill:` prefix.
- Records both payloads as bounded local evidence whenever an outbox enqueue conflicts, so the next occurrence is diagnosable.
- Adds a control beside search that returns the transcript to the latest turn and resumes auto-follow.
- Removes a recovery branch that an exhaustive test proved unreachable, along with the handlers only it reached.

## Where We Started

Alpha had proven the core loop, but daily use kept producing small
interruptions that were not real. Two different notices appeared for a second
and vanished without any action: one about Mirror synchronization, one offering
to resolve a preserved attempt. Both looked like something needed attention.
Neither did.

Underneath the first notice was a worse problem that the flicker had been
hiding. The enqueue that carries a turn to Mirror was failing with
`mirror_append_item_conflict`, and nothing on disk survived to explain why.

## What Changed

**Notices now require persistent failure.** Synchronization attention derives
from a per-Journey ledger of convergence attempts. A single failed attempt is
ordinary self-repair and stays internal; attention requires durable debt plus
failure that survived a second attempt or a bounded window. An unreadable
evidence store still surfaces, because debt cannot be derived without it.

**The conflict became evidence, then a fix.** The three native enqueue sites now
record both payloads and the differing keys beside the outbox, bounded to the
most recent records, without changing the error code or the outbox. That
evidence showed the real cause immediately: the native projection of the visible
user request kept the whole attachment block, because the frontend separates it
with one newline while the splitter expected two, and kept the entire Nautilus
synthesis prompt, because a leading `/skill:` line defeated envelope detection.

The consequence reached past the notice. The live enqueue failed closed, but
native reconciliation re-materialized the same payload and delivered it, so
Mirror received prompts the Navigator never typed. The projection is corrected
at the source; the fail-closed conflict was right and stays, and the conflict
recording remains as a tripwire.

**The preserved-attempt panel could only ever flash.** Its two inputs were read
at different times. A blocking record exists only while the exact native run is
active, while its recovery routes required that same run to be inactive. Those
cannot hold at one instant. The blocking turn is now derived from one snapshot,
and the branch that assumed otherwise was removed with the handlers only it
reached — a net deletion of roughly 250 lines.

**Returning to the end is one control.** A button beside search returns the
transcript to the latest turn and resumes auto-follow. It stays in place so the
header never shifts and is emphasized only once the reader has left the end.

## Conscious Exclusions

- No change to Pi JSONL, the turn journal, the outbox schema or Mirror Core.
- The eleven user messages already delivered to Mirror with an attachment block are left as they are, by explicit Navigator decision.
- Cancelling a turn still discards whatever partial answer had arrived; preserving it is captured as CR089 and not implemented here.
- The native `interrupt_inactive_turn_journal` command remains registered without a frontend caller.
- No search or turn-navigation behavior changed.

## What We Learned

The flicker was worth chasing for a reason that had nothing to do with polish.
Twice in this release, a cosmetic complaint led directly to a correctness
defect: once to prompts being corrupted on their way into Mirror, once to a
branch that could never run. Treating a small visible wrongness as evidence
rather than as noise is what surfaced both.

The other lesson is about proving before deleting. The unreachable branch was
removed only after an exhaustive test over the whole finite input space showed
that a blocking record and an inactive run cannot coexist. The proof came first
and the deletion followed, which is why the removal could be large without being
a gamble.

## Next Horizon

CR089 asks whether the Conversation may hold a partial answer that Pi's
transcript will never hold; that authority question is the next one to settle.
After it, the pre-beta line continues with faster model switching during a live
run, an execution indicator separate from pinning, and the context-stats gap
between the terminal and the Desktop.
