# v0.3.0-alpha.9 — The Composer Keeps Your Words

**Date:** 2026-11-02

## Highlights

- **Typing while a turn starts is safe.** Text written in the composer during Working stays there
  when the agent starts answering, and after the turn ends.
- **A cancelled turn gives the message back.** Cancel a turn before the agent wrote or did anything,
  and the message returns to the composer, with its attachments, and a note saying so. Anything you
  had typed since stays, after it.
- **Still Intel only, and not signed.**

## Where We Started

Two frictions of daily use: text typed while waiting for the agent disappeared when the answer
began, and cancelling a turn during Working lost the message that had just been sent.

## What Changed

On send, the visible composer is cleared while the sent message stays stored, so a crash before the
agent has it does not lose it. When the agent started, the app cleared that stored copy and the
visible composer with it, which by then held only new text. Now only the stored copy of the sent
message goes. A cancelled turn with no answer, no fragment and no work is treated as unanswered, and
its message comes back.

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.8. The interrupted turn stays in the
conversation, as before. Mirror Desktop 0.2 is not offered.

## Conscious Exclusions

- **A cancelled message sent again may appear twice in the conversation.** The transcript stays the
  authority over what was sent.
- **Typing and scrolling in very long conversations during a turn** are still being measured (CR182,
  CR185).
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

The suspected cause was a change of draft key; the real one was a clear meant for a stored copy
that also reached the screen. A copy kept for safety must be released without touching the original.

## Next Horizon

Why the output stalls during a turn in a long conversation: the first samples show it needs both a
running turn and the conversation's size.
