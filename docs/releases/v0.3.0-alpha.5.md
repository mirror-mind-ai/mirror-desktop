# v0.3.0-alpha.5 — Its Own Way to Claude, in the Journey's Folder

**Date:** 2026-11-02

## Highlights

- **Claude through Mirror Desktop's own Claude Code.** In Settings › Connections › Model providers,
  choose *Claude · through Claude Code* and press Connect. Mirror Desktop installs its own copy
  (about 135 MB, each package checked) and uses the Claude sign-in already on this Mac.
- **Your Claude Code stays yours.** Its plugins and hooks no longer run inside Mirror Desktop's
  turns, so a Mirror plugin installed for Claude Code no longer records Mirror Desktop's turns a
  second time. Your own Claude Code, in a terminal, is untouched.
- **Until you connect it, nothing changes:** Mirror Desktop keeps using the Claude bridge Pi already
  has on this Mac, so no one loses Claude on update.
- **The agent works in the Journey's folder.** A turn runs in the Journey's project folder, or, for a
  Journey without one, in `~/Mirror Journeys/<journey>`. Before, it ran inside your Mirror home, so a
  file the agent wrote without a path landed next to your memory.
- **A project's own agent settings are not trusted.** Its instructions (`AGENTS.md`, `CLAUDE.md`)
  reach the agent, as they do for Pi in a terminal; its `.pi/` settings, skills and packages, and its
  `.claude/` settings, do not.
- **Still Intel only, and not signed.**

## Where We Started

Two findings from using this line every day. A person who already used Mirror with Claude Code saw
each Mirror Desktop turn recorded twice: Mirror Desktop borrowed the Claude bridge installed on the
Mac, and with it every Claude Code plugin and hook. And asked "which folder are we in?", the agent
answered with the Mirror home.

## What Changed

Mirror Desktop now owns its Anthropic provider as it already owned its Pi: a pinned copy of the
open-source Claude bridge, changed in two places (hooks off; only the person's own Claude Code
settings), installed on demand and checked like Pi's. Turns now take their folder from the Journey,
and the conversation's Pi session is moved to that folder before each turn, because Pi reads its
folder from the session rather than from how it was started.

## Conscious Exclusions

- **Signing in to Claude from Mirror Desktop** is not here yet: Connect uses the sign-in Claude Code
  already holds on this Mac.
- **Your Pi skills still reach Mirror Desktop's turns,** including Mirror's `mm-*` skills, which can
  reach a home other than the one Mirror Desktop opened (CR177, next).
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

What a product borrows from the machine it runs on, it inherits whole: the version, the settings,
and the habits of the tools the person installed for something else. And a folder is not where a
process starts; it is where its session says it lives.

## Next Horizon
