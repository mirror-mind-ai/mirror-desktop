# v0.3.0-alpha.11 — Settings by Intent

**Date:** 2026-11-03

## Highlights

- **Settings grouped by intent.** Models, Mirror, You, Sound & Voice, Updates and Diagnostics.
  Settings opens on Models.
- **Claude in setup.** The step that connects a model provider offers Claude through Claude Code,
  as Settings already did, and an installed Claude lets setup go on.
- **The agent works in the Journey's project** when its path is written from the home folder
  (`~/…`), instead of in a new folder under `~/Mirror Journeys/`.
- **Still Intel only, and not signed.**

## Where We Started

Models were spoken of in three tabs (Agent, Connections, Runtime), and the Mirror home's path sat in
a diagnostic list (CR175). A Journey whose project path was `~/Code/szen_play` had its turn refused
that folder as not absolute, so the agent wrote under `~/Mirror Journeys/` (CR186).

## What Changed

- **Models** holds the providers, the default model and thinking, and Model Intents. **Mirror**
  holds the bound home, its database, the binding control, the OpenRouter key and what the Mirror
  learned. **You** holds the avatar and the appearance. **Diagnostics** holds the runtime channel
  and the current session controls.
- Setup's provider step shares the Connect block with Settings.
- A registered project path starting with `~/`, or a bare `~`, names the home folder for the turn
  and for the Journey's documents, canvas and projections. A `~user` path is still refused.

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.10. Sound & Voice and Updates are unchanged.
Mirror Desktop 0.2 is not offered.

## Conscious Exclusions

- **A correction sent in the first seconds of a turn is still refused** (CR187, next).
- A folder already created under `~/Mirror Journeys/` is left in place.
- **No signing, notarization or Apple Silicon build** yet.

## Next Horizon

CR187 and the rest of the RS026 queue.
