# v0.3.0-alpha.16 — The Last of the Line

**Date:** 2026-11-04

## Highlights

- **The last Mirror Desktop TS version.** The app is becoming **Nautilus for Mirror**, which comes
  as a new app with its own name, identifier and update channel.
- **Nothing changes in the app.** This version carries no new behaviour.
- **It proves alpha.15's promise.** An app left open on alpha.15 should show this version in its
  chip without being restarted.
- **Still Intel only, and not signed.**

## Where We Started

v0.3.0-alpha.15 (CR191) taught the chip to ask the update channel again while the app stays open.
That can only be seen in the field with a version published after it.

## What Changed

- Only the version number. The source is v0.3.0-alpha.15's, with the roadmap records for CV-013
  (Nautilus for Mirror) added beside it.

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.15. Nothing in a home's database or in the
app's preferences changes. This line's update channel keeps answering, so an installation that has
not moved to Nautilus yet keeps working and can still be updated to here.

## Conscious Exclusions

- **No rename here.** Renaming inside this line would leave the identifier, data folder and channel
  under the old name; CV-013 moves all of them together as a new line.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

Some behaviour can only be proven by the next release: a check for new versions needs a new version
to find. A release with no change of its own is a fair price for that evidence.

## Next Horizon

Nautilus for Mirror (CV-013): line 0.4 with identifier `ai.mirrormind.nautilus` and its own
channel, a script that carries this app's state across, and its own site at `nautilus.mirrormind.sh`.
