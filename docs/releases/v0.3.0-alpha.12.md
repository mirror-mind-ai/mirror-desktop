# v0.3.0-alpha.12 — The Persona Above the Answer

**Date:** 2026-11-03

## Highlights

- **The persona is named above the answer**, from the start of the turn, and stays there after the
  turn ends, after reopening the Conversation and after relaunching the app.
- **No signature trailing the answer.** A `◇ persona` line the model writes at the end is no
  longer shown in the text.
- **Still Intel only, and not signed.**

## Where We Started

On the 0.3 line the Mirror asks the model to sign its answer, and the model signs on the last line.
The surface read only a signature on the first line, so the row above each answer said "Agent" and
the signature trailed the text (CR188). Since the cutover, 94 of 126 answers in production signed
last, none first, and 32 not at all.

## What Changed

- Before Pi starts, the app tells the surface which persona the Mirror's context speaks as, and the
  turn keeps it when it settles.
- When a Conversation is loaded, the persona is read from Pi's own record of the context each turn
  was given. Only the persona's name is read; the context is not.
- An answer from before, with no context recorded, still shows the persona from its own signature,
  on its first or last line.

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.11. Which persona the Mirror chooses is the
core's decision and is unchanged. Mirror Desktop 0.2 is not offered.

## Conscious Exclusions

- **The Mirror's choice of persona** still follows one keyword, and naming a persona in the prompt
  does not choose it (CR189, recorded as a core debt; the core's persona work may replace it).
- **A correction sent in the first seconds of a turn is still refused** (CR187).
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

The first repair read the persona from Pi's record, assuming the end of a turn reads it again. It
does not: since CR184 a turn settles on the conversation already on screen. Two checks in the
development app failed before the persona was written where the settled turn keeps it.
