# v0.3.0-alpha.6 — Chapters, Tables and a Way Out of Setup

**Date:** 2026-11-02

## Highlights

- **Compaction ends cleanly again.** Since this line delivers Mirror's context as its own entry, Pi
  can start what it keeps at that context. Mirror Desktop refused that as a chapter start, so a
  compaction finished with "Pi compaction checkpoint is structurally invalid." and the chapters from
  then on were not shown. Mirror Desktop now accepts every place Pi may cut, and the missing
  chapters return from the conversation itself; nothing was lost.
- **Tables a model writes are drawn as tables.** A table whose delimiter row was written `|--:|` or
  `|:-:|` (fewer than three hyphens, which Markdown allows) appeared as one paragraph of pipes.
- **Setup can leave a home that no longer opens.** If the Mirror home this app opened before is gone
  or no longer marked, opening or creating another works on the first try. The old home's sentence
  says what it is about and goes once you choose; the two folder pickers say what each is for.
- **Still Intel only, and not signed.**

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.5. Mirror Desktop 0.2 is not offered.

## Conscious Exclusions

- **Your Pi skills still reach Mirror Desktop's turns,** including Mirror's `mm-*` skills (CR177, next).
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

A check written for what a tool did once becomes a refusal of what it does next. The chapter check
and the table reader both held a narrower rule than the format they read.

## Next Horizon

What the person's Mirror skills may reach from a Mirror Desktop turn (CR177), then telling the
development build and its conversations apart from the person's own (CR168, CR169).
