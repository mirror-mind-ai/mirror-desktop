# v0.2.0-alpha.17 — Thinking Made Visible

**Date:** 2026-09-22

## Highlights

- Shows the agent's thinking for every model that produces it, instead of only for OpenAI Codex.
- Presents narrative reasoning as a collapsible Thinking block that opens while streaming and collapses once settled, with the tools it motivated nested inside it.
- Keeps the existing action-chip presentation unchanged for reasoning that already arrived in that shape.
- Reconstructs reasoning from the Pi session, so it survives closing and reopening the application rather than existing only in the live run.
- Bounds captured reasoning at 8 KB per block and 64 KB per turn, applied when it is captured rather than when it is drawn.
- States plainly when reasoning was truncated or elided at those limits, instead of trimming it silently.

## Where We Started

The Desktop showed reasoning only when the provider was OpenAI Codex. With an
Anthropic model the conversation surface showed a row of tool calls and never
the thinking that led to them: the user could see what the agent did and never
why.

The cause was not a format incompatibility, which is what it looked like from
the outside. Pi emits thinking events uniformly for every provider. The Desktop
carried a hardcoded provider allowlist and a second per-message gate, and for
anything that was not Codex it dropped those events on the floor. The reasoning
was produced by the model, durably recorded by Pi, and discarded by us.

A second loss sat underneath it. Reasoning survived only if it had been
captured live and pinned into terminal evidence. Rebuilding a conversation from
its Pi session restored messages and tool calls and silently lost the
reasoning, even for Codex, where live capture had always worked.

## What Changed

Reasoning capture became model-agnostic. The allowlist, its per-message
companion and the provider predicate behind them are gone. Admission is now
driven by the events themselves, which exist only when a model actually
produced thinking.

Presentation follows the shape the model produced rather than forcing one shape
onto both. Codex tends to emit short summaries, often a sequence of standalone
titles, and those keep becoming the action chips they always were. Anthropic
models emit narrative prose, typically a block before each tool call, and that
now becomes a Thinking block carrying the full text under a title taken from
the model's own words by truncation. Nothing is synthesized: a title is the
model's prose cut short, never a label invented to describe it.

Reasoning also became durable in the way the rest of the conversation already
was. The Pi session inspection already carried the raw content blocks; the
surface projector simply was not reading them. It now reconstructs thinking and
tool calls in their recorded order, correlating tool outcomes by exact
identifier, and live capture always takes precedence over a reconstruction.
The reconstruction is recomputed from Pi rather than stored, so the session
remains the single authority.

Both paths share one definition of the capture bounds, so they cannot drift
into disagreeing about what a turn's reasoning was.

## Conscious Exclusions

- Reasoning already absent from stored conversations is not backfilled; only what Pi recorded can be shown.
- Reconstructed turns report a completed run outcome, because the Pi session records no terminal run status; live evidence, which knows, always wins.
- A tool call with no recorded result is reported as interrupted rather than guessed at.
- Titles are truncation, not comprehension: an uninformative first line yields an uninformative title, with the full text one click away.
- No change to Pi invocation, provider authentication, model selection, transcript authority or Mirror synchronization.

## What We Learned

The defect looked like a model incompatibility and was actually a decision we
had made and forgotten. Building against one provider is reasonable; freezing
that provider's name into a gate is how a reasonable starting point becomes a
silent restriction. The uniform event contract had been there the whole time,
and we were the ones narrowing it.

The second loss taught a sharper lesson. We had established that the Pi session
is transcript authority, and we were not reading all of it. Declaring a source
authoritative does not make a projection complete; the parts you never read are
the parts you quietly lose.

## Next Horizon

Watch how the bounds behave against genuinely long reasoning in daily use, and
revisit them with measurements rather than estimates if they bite. The adjacent
unbounded field in the same structure, tool output, remains the larger
contributor to conversation growth and is the natural next thing to
characterize.
