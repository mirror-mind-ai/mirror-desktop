# v0.1.0 — Private Alpha and Trusted Self-Update

**Date:** 2026-09-08

## Highlights

- Establishes the private macOS alpha handoff path for Mirror Desktop.
- Adds release candidate provenance checks for version, tag, revision, checksum, architecture, and source state.
- Adds trusted self-update discovery, installation planning, consent, quiescence, and recovery contracts.
- Implements the in-app update path with Tauri's signed updater boundary.
- Validates a private HTTPS clickable rehearsal from one installed app version to the next.
- Refines the update notice into a discreet header version chip that remains visible when up to date.

## Where We Started

Mirror Desktop inherited a functioning Tauri application body from Nautilus Harness, but release distribution still depended on direct private handoff. A user could run the app, but the application did not yet have a trustworthy way to tell them a new version existed, explain the preservation boundary, update itself, and return to the same Journey context.

The first alpha also needed a clean separation between application bytes and Mirror state. The updater had to be allowed to change the desktop app without treating Mirror homes, identity, conversations, credentials, app data, or Nautilus Harness state as part of the artifact.

## What Changed

The alpha release path now records provenance before a bundle is handed off. The release candidate inspection checks that package, Tauri, and Cargo versions agree, derives the expected Git tag, records the full source revision, names the architecture-specific artifact, and preserves the boundary that inspection does not publish, sign, notarize, push, tag, or self-update.

Trusted self-update is now a real in-app capability. The frontend checks Tauri's updater channel, presents availability through a compact version chip, opens an explicit update popover, blocks update while runtime work is active, downloads the signed updater artifact, installs it through the native updater boundary, and relaunches the app. Settings keeps a fuller Updates panel for manual inspection and recovery context.

A private HTTPS endpoint at `updates.mirrormind.com.br` was prepared for rehearsal. The installed-app flow was validated from `0.1.0` to `0.1.1`, then through additional UX rehearsals. The evidence confirmed manifest fetch, artifact download, signature-backed updater packaging, application replacement, relaunch, and current-version follow-up checks.

## Conscious Exclusions

- This release note does not declare a public production release.
- No production signing-key custody process is established here.
- macOS notarization remains outside this alpha boundary.
- The private HTTPS endpoint is suitable for rehearsal, not yet a governed production release channel.
- Mirror Core installation and migration remain outside the desktop updater.
- Mirror homes, `memory.db`, identity, credentials, Journey content, conversations, app data, and Nautilus Harness state are not updater targets.
- Creating this note does not authorize pushing commits, creating Git tags, publishing GitHub Releases, uploading production artifacts, or changing stable user installations.

## What We Learned

A desktop self-update feature is only partly code. The actual trust boundary appears when the app, the signed artifact, the manifest, the endpoint, and the user's local state all meet. The useful validation was not the green build alone; it was the moment an installed app saw a newer version, asked for consent, replaced itself, returned, and still belonged to the same local world.

The UX followed the same lesson. An update should not interrupt the Journey unless it must. A small version chip is enough: quiet when current, gently actionable when a new application is available.

## Next Horizon

The next release boundary should harden the private updater channel into a repeatable release process: durable key custody, versioned release-note publication, manifest generation from provenance, artifact retention policy, notarization decisions, and an explicit promotion route from private rehearsal to production distribution.
