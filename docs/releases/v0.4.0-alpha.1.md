# v0.4.0-alpha.1 — Nautilus for Mirror

**Date:** 2026-11-04

## Highlights

- **Nautilus for Mirror.** The app is called Nautilus for Mirror in the Dock, Finder and window,
  and Nautilus in its menu. Its words say Nautilus, and the violet spiral it had as Nautilus
  Harness is its icon again.
- **A new app, beside the old one.** Its bundle identifier is `ai.mirrormind.nautilus`, so it has
  its own data folder and its own update channel (`updates.mirrormind.sh/nautilus`). Mirror Desktop
  TS stays installed and works as before, as the way back.
- **The state comes across.** `scripts/carry_03_state.mjs` copies the 0.3 app's data folder into
  Nautilus's: every home's Journeys, Conversations and Pi sessions, Pi and Claude Code as
  installed, the model settings, the OpenRouter key and the avatar. It also repairs, on proof, the
  older history the 0.2 carry had left failing its checks (CR192).
- **Still Intel only, and not signed.**

## Where We Started

v0.3.0-alpha.16 closed the Mirror Desktop TS line. The Navigator chose to rename the app and to move
every machine coordinate with the name (CV-013), so that new people arrive with the identifiers the
product will keep.

## What Changed

- **Name, identifier and channel** (CV-013.DS-002, slice 1): release line 0.4 under
  `ai.mirrormind.nautilus`; the release gate knows three lines and refuses any crossing.
- **The words** (slice 2): the interface, native messages, the microphone permission and the
  release route's output say Nautilus.
- **Labels in data** (slice 3): prompts open with `[Nautilus Journey authority]`, Pi sessions end
  `· Nautilus · Generation N`, and new Mirror Conversations carry the interface `nautilus` (CR171).
  Older prompts and labels are still read, and Mirror's learning reads both labels.
- **The icon**: the Nautilus Harness spiral (`0c4684cb`), with its `DEV` and a new `EVAL` badge.
- **Carrying the state** (CV-013.DS-003): a dry-run-first, all-or-nothing script that never writes
  the 0.3 folder, clones files on APFS and moves only the structural session paths.

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.16. The Mirror home does not move and its
database is not touched. The 0.3 channel keeps answering for the installations still on it.

## Conscious Exclusions

- **No automatic move from 0.3.** Mirror Desktop TS is not offered this version: a different app
  cannot be installed over it. Nautilus is installed from its DMG and the state is carried by hand.
- **The repository and package names** stay `mirror-desktop` for now.
- **The sites** still say Mirror Desktop until CV-013.DS-005.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

A rename is cheap in words and costly in coordinates: identifiers, folders, channels, stored labels
and the hashes that guard history all carry the old name. Rehearsing the carry on a clone of
production found two defects before they could reach anyone: a copy that did not clone, and history
receipts the previous carry had left stale.

## Next Horizon

The Navigator's cutover (CV-013.DS-004), then the sites (DS-005): `nautilus.mirrormind.sh`, and the
Mirror site pointing to Nautilus.
