# v0.3.0-alpha.4 — An Exit That Says What It Did

**Date:** 2026-11-01

## Highlights

- **Recover this turn always answers.** If recovery cannot run yet, a sentence under the button says why: another recovery is still in progress, the app has not yet read which agent runs are live, an agent process is still running in this Journey, or this window still believes the agent is answering.
- **A recovery that ran but could not close the turn says so,** and names the file where the reason is recorded, instead of leaving the notice as it was.
- **Nothing else changes.** Same Mirror core (`mirror-mind` 0.39.0), same Pi, and recovery is held off in exactly the same situations as before.
- **Mirror Desktop 0.2 is not offered this version.** Its channel still names 0.2.0-alpha.58.
- **Still Intel only, and not signed.**

## Where We Started

While a real Mirror was being rehearsed on this line, a turn finished but the conversation never
heard it end. The application offered *Recover this turn*; it was pressed, and nothing happened. No
record changed and nothing on the screen said why. 0.3.0-alpha.3 fixed the cause of that stranded
turn, but the button that did nothing remained.

## What Changed

The recovery behind the button has always held itself off in four situations, so that it never
touches a Journey's records while work in it is still live. Those situations are unchanged. Each one
now has a name, the recovery reports what it did, and the notice shows that report under the button.

## Conscious Exclusions

- **The recovery itself does not do more yet.** Which situation held it off in the field is not
  known; the sentence this release adds is what will tell, and the next change follows from it.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

An exit that does nothing is worse than no exit: it spends the trust of the person who pressed it
and leaves no trace of why. The first duty of a recovery that cannot act is to say so.

## Next Horizon

Read the sentence the next time it appears, and let it decide whether the recovery should act in
that state. Then the queue of work left for after the move continues, starting with saying why a
provider refused a turn.
