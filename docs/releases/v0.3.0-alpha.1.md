# v0.3.0-alpha.1 — A Mirror of Its Own

**Date:** 2026-10-31

## Highlights

- **A new application, Mirror Desktop TS, with Mirror inside it.** It carries its own Node and Mirror's core (`mirror-mind` 0.39.0), so nothing else has to be installed first.
- **The first screen gets you to a first answer without a terminal:** create your Mirror (a name and a place, `~/Mirror Homes` by default), install Pi, sign in to an AI provider, and give the OpenRouter key Mirror's context needs. The key is kept in your Keychain.
- **Mirror is in the Conversation from the first turn.** Each turn receives Mirror's context before the model answers.
- **The mirror learns while a Conversation stays open.** After 30 minutes without a new message, what was said since the last time becomes memories. Nothing waits on it, and the Conversation is never closed.
- **Journeys are managed in the app:** create one, change its name, description and status, move it, set its project folder, or delete it while it is empty.
- **It stays apart from everything you already have.** Mirror Desktop and the Mirror you use from the terminal are not opened, read or changed, and Mirror Desktop's updates never offer this application.
- **Intel only, and not signed.** macOS refuses the first open; System Settings › Privacy & Security then offers **Open Anyway**.

## Where We Started

Mirror Desktop assumed Mirror was already installed. It talked to it through Mirror's Python
command line, so a person needed a terminal, Python, uv, a Mirror installation and Pi before the
first screen could do anything.

Meanwhile Mirror's core moved to TypeScript. On 2026-10-28 Mirror Desktop decided to follow it:
its 0.2 line stayed frozen on the Python Mirror at alpha.58, and a 0.3 line began that embeds the new
core inside the application. This is the first release of that line.

## What Changed

**Mirror runs inside the application.** A small host process, started with the Node the app
carries, loads Mirror's core as a library and answers the app's requests: the Journey tree and its
Conversations, recording each turn, Mirror's context for a turn, learning, and Journey changes. The
core is the published `mirror-mind` 0.39.0, the same one the terminal installs, checked by its hash
when the app is built.

**The first run.** On a Mac with no Mirror, the first screen offers *Create your Mirror*. The home
is built beside its target and appears complete or not at all. Pi is installed into a folder the app
owns, from a pinned list of exact packages. A model provider is connected through Pi's own sign-in,
and the OpenRouter key is stored in the Keychain. The key is passed to Mirror for
each turn and never written to a file.

**Learning without ending.** On the terminal, the mirror learns when a Conversation ends. A
Conversation in the app is never ended, so instead the app asks Mirror, at launch and while idle, to
learn from what each Conversation gained since it was last learned from. A Conversation is ready
after 30 minutes without a new message. A failed attempt is retried later; a turn never waits on it.

**Journeys.** The Journey menu creates, edits, moves and deletes Journeys through Mirror's own calls,
and the sidebar shows the tree Mirror answers with. Editing a Journey's name, description and status
is new: Mirror Desktop 0.2 offered it but no Mirror could save it. If the Journey changed elsewhere
since the form opened, the form reloads it instead of overwriting.

**Its own channel.** Updates come from `/mirror-desktop/ts/`. Mirror Desktop 0.2 polls a different
channel, and the publication route refuses to put a 0.3 version on it.

## Conscious Exclusions

- **The Mirror you already use is not opened or moved.** Bringing an existing Mirror into the application is a later step, done only with care for that home's data.
- **Mirror Mode only.** Builder, Explorer and Soul modes, skills and operating instructions do not return in this line yet.
- **No signing or notarization, and no Apple Silicon build.** Both are owed before 0.3 is offered publicly; this alpha has not been run on Apple Silicon.
- **The site's download link still offers Mirror Desktop 0.2.** This alpha is installed from its own channel.
- **A Journey's id cannot be changed.** Its Conversations, memories and tasks are kept under it.

## What We Learned

**Ending is the terminal's idea, not the person's.** The plan was to end an idle Conversation and
learn from it as the terminal does. Measured first, that broke the app: a Conversation in the app
lasts as long as the thread, and later turns would have landed in an ended Conversation. Learning
from the newest stretch, behind a mark, kept the Conversation whole and still taught the mirror.

**An edit that never worked was a missing call, not a missing screen.** Mirror Desktop had offered
Journey editing for months, then hid it when no Mirror could save it. Once Mirror's core gained the
call, the screen needed only to send what changed.

## Next Horizon

This alpha starts seven days of daily use on a Mirror of its own. A second release follows, to prove
the application updates itself. After that, the paused small fixes resume, and signing and an Apple
Silicon build come before a public 0.3.
