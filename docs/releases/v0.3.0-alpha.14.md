# v0.3.0-alpha.14 — Only the Canonical Set

**Date:** 2026-11-04

## Highlights

- **A Journey opens on its Conversation alone.** With no extension turned on, the surface tabs are
  not drawn.
- **Settings › Extensions** turns on the **Agent Field** and the **Agent Canvas**, each adding its
  tab beside Conversation. Both are off by default, on every installation.
- **Two names change:** the Context Map is now the Agent Field, and Agent's Canvas is now Agent
  Canvas.
- **Still Intel only, and not signed.**

## Where We Started

CV-012 decided that the app ships a small canonical set (Journeys, personas and their
conversations) and that everything else becomes an extension the person turns on or off. The
extension mechanism does not exist yet, and the launch should not show functions that will later
leave the core: hiding them now avoids taking them away afterwards (CV-012.DS-001).

## What Changed

- **CV-012.DS-001, the Extensions tab.** A seventh Settings tab says that extensions are still
  being built and that its options bridge what exists today to how it will work. It holds two
  switches whose state reads in words as well as in colour.
- **The tabs beside Conversation** follow the switches. A switcher with only Conversation left is
  not drawn, and a Journey remembered on a surface that is now off opens on its Conversation.
- **The Agent Canvas is read only while it is shown**, so turning it off also stops reading the
  drawing from disk.
- **A Journey document clicked in a conversation** opens in the Agent Field when it is on, and
  outside the app, like any other local file, when it is off.

## What Does Not Change

The same Mirror core and the same Pi as v0.3.0-alpha.13. Nothing in a home's database or in a
Journey's files changes; the switches are kept with the app's preferences for each home, and the
surfaces keep their stored ids. Ariad and the Tactical and Strategic altitudes were already hidden
and stay so. Mirror Desktop 0.2 is not offered.

## Conscious Exclusions

- **The extension mechanism itself** (installing, versioning, contributing surfaces) is CV-012's
  later work, after the launch.
- **Switches for Ariad and the altitudes** are not offered; they are not ready to be turned on.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

The design that shipped was neither of the two proposed: not a switch per function, not a method
switch above them, but a tab that says honestly that the mechanism is still on its way. And two of
the five functions the launch had to hide were already hidden, which left exactly the two the
Navigator named.

## Next Horizon
