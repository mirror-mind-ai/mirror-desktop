# CV-003.DS-001.US-3 — Strategic Journey Preview

**Status:** 🟡 Planned
**Type:** User Story

## User Story

As the Navigator,
I want to view representative realizations, impacts and value at a wider altitude,
so that I can feel what the Journey has produced in pragmatic and integrative terms.

## Outcome

Strategic presents a spacious, visibly provisional reading that connects one realization to impacts and complementary value lenses.

## Acceptance Behavior

```text
Given the shared representative Journey model
When I select Strategic
Then realization, impact, pragmatic value and integrative value remain visibly related
And no synthetic score or authoritative live claim is shown.
```

## Scope

- Realization selection/presentation.
- Impact composition.
- Pragmatic and integrative value lenses.
- Strategic density and preview labeling.

## Out Of Scope

- Executive reporting metrics.
- Live semantic derivation.
- Value scoring or ranking.

## Validation

Static component tests and real desktop Scenario 5/6 review.
