# CV-003.DS-002 - Operational Journey Artifacts

**Status:** 🟡 Planned

## Outcome

Navigator can inspect a bounded, read-only projection of folders and files from the selected Journey path beside the live conversation.

## Done Condition

The Operational view reflects the active Journey workspace, supports clear folder/file navigation, preserves allowed-root link safety, does not grant mutation authority, and does not disturb conversation continuity or runtime activity.

## Boundary

This story makes workspace artifacts visible. It does not attach files to prompts automatically, derive tactical meaning, edit files or duplicate the future explicit attachment boundary of DS-007.
