# TS-1 Characterization — Local Transcription Spike and Contract

**Date:** 2026-09-23
**Machine:** 2019 MacBook Pro, Intel Core i7-9750H (6 cores / 12 threads), macOS 26.6.2, no Metal (CPU + Accelerate).
**Engine:** `whisper.cpp` v1.8.3 (`2eeeba5`), built with `cmake -DBUILD_SHARED_LIBS=OFF -DGGML_METAL=OFF -DCMAKE_BUILD_TYPE=Release --target whisper-cli`. Result: `whisper-cli`, 2.6 MB Mach-O x86_64 linking only `libSystem`, `Accelerate` and `libc++`.
**Samples:** macOS `say` speech (Luciana pt_BR, Samantha en_US) converted with ffmpeg to 16 kHz mono PCM16 WAV. Synthetic voices are harder than natural speech for proper nouns; results are conservative.

## Runtime observations

- `--language auto` roughly doubles wall time on base (18.1 s vs 8.8 s for the PT clip) because detection runs an extra encoder pass. Detection itself was correct (`pt`, p = 0.98).
- `--threads 8` was slower than the default 4 on this CPU (19.4 s vs 8.8 s); hyperthread contention. The boundary keeps the executable default.
- Encode time dominates (5.7 s of 8.8 s). It scales with 30-second windows, so a five-minute clip needs roughly 60–120 s on this machine; the native timeout is 10 minutes and the UI offers Cancel.
- `--no-prints` keeps stdout to the transcript only (one leading blank line and leading space, handled by normalization). Timings go to stderr.
- Apple Silicon builds should enable Metal; this Intel machine is the slow floor.

## Portuguese regression, 2026-09-23

The Navigator reported that Portuguese was not being understood in the packaged build. Two independent causes were measured against the reference sentence "Quero revisar o roadmap do Mirror Desktop e preparar a próxima história de entrega sobre transcrição de voz.", captured at 48 kHz.

**1. Unfiltered decimation.** The shipped conversion interpolated 48 kHz straight to 16 kHz with no anti-aliasing, folding everything above 8 kHz back into the speech band. Comparing the same audio through plain interpolation and through ffmpeg's filtered resample, on `small-q5_1`:

| Conversion | Transcript |
|---|---|
| linear interpolation (shipped) | "o roadmap do **MiRO 10** que **topa**" |
| ffmpeg filtered | "o roadmap do **Mirror 10** que top" |

Replacing the resampler with band-limited windowed-sinc interpolation (16 zero crossings, Blackman window, polyphase kernel table) now reproduces the ffmpeg result exactly. A 12 kHz tone resampled to 16 kHz drops from 0.5+ peak amplitude to under 0.02, while a 1 kHz tone keeps over 0.98. The phase table removes the trigonometry from the inner loop: 7.3 s of 48 kHz audio converts in 54 ms instead of 1483 ms, so a five-minute recording costs roughly 2 s rather than a minute.

**2. The default model was too small for Portuguese.** With conversion fixed, the model still decides the outcome:

| Model | Download | Portuguese | Wall time, 7.3 s clip |
|---|---:|---|---:|
| base-q5_1 | 57 MB | "o **roo de MEP do Mi Rordeis**" — unusable | 6.9 s |
| small-q5_1 | 181 MB | "o roadmap do Mirror 10 que top" — usable | 18.1 s |
| large-v3-turbo-q5_0 | 547 MB | "o roadmap do Mirror Desktop" — correct | 64.5 s |

Both timings are for a 2019 Intel i7 without Metal; Apple Silicon with Metal is far faster. Because the right trade-off depends on the machine, the model became an explicit choice in the install dialog and in Settings → Voice, with `small-q5_1` as the recommended default. Switching models redownloads only the model and replaces the installed one.

`large-v3-turbo-q5_0` sha256 `394221709cd5ad1f40c46e6031ca61bce88931e6e088c188294c6d5a55ffa7e2`.

## Decisions recorded for DS-005

- **Default model:** `small-q5_1`, with `base-q5_1` and `large-v3-turbo-q5_0` offered alongside it. `base-q5_1` was the original default and was demonstrably unusable for Portuguese; see the regression section above.
- **Engine:** `whisper.cpp` v1.8.3 `whisper-cli`, statically linked per platform/architecture; macOS aarch64 builds with Metal, x64 without.
- **Language:** `auto` by default for correctness; an explicit hint halves latency and is a candidate Settings refinement, not part of this Delivery Story.
- **Limits:** 5-minute recordings, 9.6 MB WAV bound, 10-minute transcription timeout, transcript bounded by the Composer draft limit.
- **Capture:** WebView `getUserMedia` + `MediaRecorder`, TypeScript WAV conversion (no ffmpeg). Downsampling must be band-limited; plain interpolation is a correctness defect, not a quality preference. WebView permission behavior remains Navigator validation in `Mirror Desktop Dev`.
- **Hosting:** Mirror-controlled `https://updates.mirrormind.sh/mirror-desktop/voice/manifest.json`; artifacts curated with the manifest helper. Publication is a separate release gate.
- **Licenses:** `whisper.cpp` is MIT; Whisper model weights are MIT. Redistribution is compatible.
