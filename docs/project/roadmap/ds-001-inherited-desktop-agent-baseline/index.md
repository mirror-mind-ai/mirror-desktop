# DS-001 - Inherited Desktop Agent Baseline

**Status:** ✅ Done

## Outcome

Nautilus Harness already has a working desktop agent cockpit baseline inherited from the parent Nautilus delivery arc.

## Delivered Baseline

The current app includes:

- Tauri 2 desktop shell;
- Vite, React and TypeScript frontend;
- Journey sidebar;
- central agent chat;
- right-side realization grammar panel;
- mock agent streaming;
- explicit live local Pi invocation;
- Pi response normalization;
- grammar projection into the side panel;
- safe rich assistant message rendering;
- clear chat control;
- local no-session Pi invocation by default.

## Why This Is Done

This work was delivered under the parent Nautilus roadmap before the Harness child roadmap became the delivery authority for application operability.

## Boundary

This record documents inherited baseline only. It does not claim provider configuration, cancellation, local history or workspace context attachment are done.
