# DS-007 - Workspace Context Attachments

**Status:** 🟡 Planned

## Outcome

Navigator can attach bounded local context to an agent request without granting broad uncontrolled filesystem authority.

## Boundary

This delivery concerns explicit context selection only. It does not let Pi freely browse the filesystem, mutate files without confirmation, integrate Mirror or execute Nautilus Missions.
