## Continuous Thickening Narrative

The landing page should stop introducing Mirror Mind as an infrastructural object and start with the experience it creates. Approved hero: H1 'AI agents that remember where you left off.' Supporting line: 'Mirror Mind gives your agents a local memory of who you are, what you are building, and the journeys already in motion.' Continuity line: 'Your identity, memory, personas, attachments, and skills stay with you, turning separate AI sessions into one continuous working relationship.' The screenshot should move from the desktop alpha section into the hero. The separate desktop alpha section should be removed. The next section, 'what changes', should use four experiential cards: Remember the thread; Keep the work in motion; Choose the surface; Keep memory local. The following section should be titled 'four ways to cross the terrain' and present Mirror, Explorer, Build, and Soul as lived modes rather than technical features. Approved mode texts: Mirror, 'Return to yourself before deciding. Use the agent as a reflective surface for sensemaking, positioning, writing, and life direction.' Explorer, 'Hold uncertainty without rushing into implementation. Let possibilities thicken before they become commitments.' Build, 'When the direction is clear, move into construction. Edit code, shape docs, run validations, and preserve the reasons behind the work.' Soul, 'Enter a quieter listening mode for inner life. Not productivity, not advice, but a ritual surface for what is asking to be heard.' Header should be: mirror mind, what changes, modes, core, desktop. Footer should be: mirrormind.sh, English / developers, Mirror Core, Mirror Desktop, Português: mirrormind.com.br. Do not include Windows or updates in the footer. Do not deploy, mutate DNS, push, publish releases, tag, notarize, or change Mirror/app user data as part of this handoff.

## Current Exploratory Story

mirrormind.sh is becoming a simple English developer-facing doorway for Mirror Mind, organized around experiential continuity rather than technical inventory. The approved page shape is now: hero with experiential copy and Mirror Desktop screenshot, a 'what changes' section, a 'four ways to cross the terrain' modes section, and a restrained navigation/footer that supports orientation without turning the page into documentation.
